# 🔒 Cybersecurity Risk Assessment of an Online Learning System

> A comprehensive risk assessment and vulnerability analysis case study for an educational institution's online learning platform.

---

##  Project Overview
This repository contains the complete case study and presentation for a structured cybersecurity risk assessment. The project focuses on safeguarding critical academic assets—such as student databases, web servers, and course files—by identifying threats, evaluating qualitative and quantitative risks, and establishing robust security controls.

---

##  Project Nature & Collaboration
* **Collaborative Team Effort:** This case study was developed as a joint academic project, bringing together structured analysis across various domains of risk management.
* **My Core Contributions:** 
  * Designed the comprehensive **Vulnerability Scanning Plan** (defining authorized scope, timing, and methodology).
  * Analyzed and categorized **Scan Results** based on severity levels.
  * Evaluated **Residual Risks** and established continuous post-scan monitoring strategies.
  * Authored the final **Conclusion and Actionable Recommendations**.
